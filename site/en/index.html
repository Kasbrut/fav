Your server. Your VPN.

FAV turns a dedicated Debian or Ubuntu server into a WireGuard endpoint. It connects directly over SSH, runs inspectable setup scripts, and helps you manage client profiles from one app.

Read the setup guide View the source
Early-release software

Use a dedicated server and keep your provider’s recovery console available. FAV changes SSH, firewall and network configuration.

From a fresh server to a working tunnel

FAV handles the server side. You still use the official WireGuard app, or another compatible client, to connect.

1

Connect

Enter the server address and SSH credentials. Passwords are used for the current operation and are not stored.

2

Verify

Compare the SSH fingerprint with your provider’s console before trusting the server for the first time.

3

Provision

Follow each installation step. The detached installer can recover after an app restart or a network change.

4

Import

Create one peer per device, then import its profile into WireGuard using a file or QR code.

Manage it without leaving the app

Once the server is running, FAV remains a practical administration tool rather than a one-time installer.

Peers and profiles

Add, rename and revoke peers. Export each client profile as a configuration file or show its QR code for another mobile device.

Live status and history

Review recent handshakes, traffic and connection history so you can tell which peers are active and when they last connected.

Built-in SSH shell

Open an interactive terminal to a managed server. It uses the same pinned host identity and protected credentials as other FAV operations.

Encrypted backup and restore

Move your managed servers, SSH identities, peer profiles and transferable settings to a clean device using a password-encrypted backup. Restore checks each reachable server before completing.

Access and cleanup

Add your own SSH public keys, check the WireGuard port, and remove either FAV's local record or the services it installed on the server.

Clear boundaries matter

No hosted control plane

The app talks directly to your server. FAV has no account system, subscription or remote service that controls your installation.

Not a VPN client

FAV creates and manages WireGuard profiles. A separate WireGuard client installs the tunnel on each device.

Designed for dedicated servers

Provisioning changes shared network and SSH configuration. Do not use a machine that carries unrelated production workloads.

Recovery remains your responsibility

Safeguards reduce lockout risk, but they cannot replace provider-console access or an independently tested SSH key.
