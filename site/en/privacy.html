Privacy policy

FAV has no user accounts, analytics, advertising or tracking SDKs. Server and peer data stays on your device unless you choose to export or share it.

Data collection

The FAV project does not operate a backend service that receives app usage, server details, credentials or diagnostics. The app does not collect telemetry and this website does not use analytics or cookies.

Data stored on your device

FAV stores the servers you add, installation state, peer records, preferences and monitoring history locally. Structured records are encrypted. Their encryption key, generated SSH keys and client profiles are kept through the operating system’s secure-storage facilities.

SSH passwords are not persisted. They are requested when an operation needs them and held in memory for that operation.

Network connections

The app connects directly to servers you specify over SSH. During provisioning, the server contacts its APT repositories and may contact api.ipify.org to discover its public IPv4 address. Restoring a backup contacts the listed servers to verify access and can perform the recovery actions you explicitly select. Help, source and issue links open in your browser only when selected.

GitHub may process ordinary web request data when you visit this documentation or the project repository. That processing is governed by GitHub’s own privacy statement.

Data you choose to share

Exporting, copying or displaying a WireGuard profile exposes that peer’s private configuration to the chosen recipient. A .favbackup file contains server records, pinned fingerprints, FAV SSH keys, peer profiles, custom scripts and transferable settings, protected by the password you choose. Keep both the file and password private. Passwords, app-lock settings, diagnostics and monitoring history are not included.

Diagnostic exports are scrubbed, but you should still review them before sharing, especially after using custom scripts. A factory reset removes local FAV data. It does not remove running services or keys from a remote server.

Contact

Questions about this policy can be opened as a public discussion or issue once the repository is available. Security-sensitive information belongs in the private vulnerability-reporting form.
