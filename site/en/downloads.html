Downloads

FAV 1.0.1 is available from GitHub Releases for Android and Linux. Android testing through Google Play is currently limited to invited testers.

Availability

  • AndroidSigned universal and per-architecture APKs on GitHub; testing on Google Play.
  • Linux x64AppImage and Debian package on GitHub.
  • Windows x64Not yet published; public installers require code signing.
  • macOSNot yet published; public builds require signing and notarization.
  • iOS and iPadOSNot yet published.

Android release channels

Google Play and the APKs published on GitHub use different signing keys. Android therefore treats them as separate update channels: an installation from one channel cannot be updated by the other.

To switch channels, first export a FAV backup, uninstall the existing app, install from the new channel and restore the backup. Uninstalling without a backup removes FAV’s local data and credentials.

Verify a download

Each GitHub release includes platform-specific SHA-256 manifests. Compare the downloaded file with the matching entry before installing it. Signed platforms should also show the expected publisher in the operating system’s signature check.

Do not install packages copied to file-sharing sites or attached to issue comments.
