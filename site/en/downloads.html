Downloads

The first public release is being prepared. Until it is published, use test builds only when they come directly from the project maintainer.

Planned availability

  • AndroidSigned APKs on GitHub, followed by Google Play.
  • Linux x64AppImage and Debian package.
  • Windows x64Signed installer and portable archive.
  • macOSSigned and notarized disk images.
  • iOS and iPadOSApp Store distribution after the GitHub and Google Play releases.

A platform will be listed as available only after its installable package has been published and tested.

Verify a download

Each GitHub release will include platform-specific SHA-256 manifests. Compare the downloaded file with the matching entry before installing it. Signed platforms should also show the expected publisher in the operating system’s signature check.

Do not install packages copied to file-sharing sites or attached to issue comments.
