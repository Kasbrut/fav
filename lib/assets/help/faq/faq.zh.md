# 常见问题

## 一句话说明，什么是 VPN？

VPN 是你的设备与一台服务器之间的隧道：你设备的流量看起来像是从服务器发出的，而你的设备与服务器之间的连接是加密的。

## 我为什么需要自己的服务器？

你可以控制 VPN 服务器及其配置，但仍需信任托管服务商和服务器管理员，他们可以观察网络元数据。自建 VPN 并不能让你匿名。

## 运行成本是多少？

FAV 免费。托管和流量费用取决于服务商及套餐，请查看其最新价格和流量限制。

## 我输入到应用里的密码会保存在设备上吗？

应用在需要时询问登录和 sudo 密码，不会将其保存为应用数据。即使未启用加固，SSH 密钥也会在安装过程中生成，并保存在安全存储中。

## 我能把服务器迁移到另一台设备吗？

可以。打开“设置”→“备份与恢复”，创建受密码保护的 `.favbackup` 文件。请只将它恢复到空的 FAV 安装中，并避免同时从两台设备管理同一服务器。如果旧设备丢失或遭到入侵，FAV 可以轮换其 SSH 密钥，并在两次确认后撤销可访问服务器上的所有现有对等设备。

## 应用能自动让我的设备走 VPN 吗？

暂时还不能。目前应用负责配置服务器——你的设备通过官方的 WireGuard 应用进行连接。把客户端功能内置到本应用中是长期路线图上的内容。

## "启用加固"有什么作用？

加固（在高级选项中，默认关闭）会在安装后锁定整台服务器：关闭 SSH 密码登录（仅允许密钥登录）、禁用 root 的 SSH 登录，并添加暴力破解防护。它作用于应用管理服务器所用的用户——以 root 登录时它创建的用户，或以非 root sudo 用户登录时你的现有用户。应用会先确认你的密钥登录可用，若有异常会自动回滚，但仍请准备好你的服务商控制台作为退路。

## 如何删除服务器？

在「服务器」中滑动服务器、使用其菜单，或在详情中选择删除服务器。选择 **删除 VPN 和服务**，FAV 会先远程清理再忘记服务器；适用时还可撤销 SSH 加固。保持该选项关闭并选择 **断开 FAV 并删除**，只会远程删除 FAV 的 SSH 密钥，VPN 仍会运行。**不联系服务器直接忘记** 只删除本地数据，并保留所有远程更改（包括 FAV 的 SSH 密钥）；仅在服务器无法访问或你会自行清理时使用。远程步骤失败后可重试，再决定是否仅在本地删除。

## 我遇到了问题——该怎么办？

如果你看到了红色错误提示，请查看本帮助标签页中的 **错误代码** 部分。如果仍然找不到解决办法，请使用 **报告问题** 来打开一个预填好的 GitHub issue。

## IPv6 与配置安全

新的 v2 配置包含 IPv4 和 IPv6 默认路由；FAV 没有 IPv6 绕过设置。只有在验证服务商委派的 `/64` 的返回路径后才使用路由 IPv6。否则，阻止模式会在 ULA 隧道中捕获 IPv6 并在服务器上拒绝它，而非使用直接 IPv6。公共 IPv6 端点不是该证据。

FAV 仅验证服务器结果和生成的配置。导出、声明已导入和 WireGuard 握手不会验证目标客户端的路由或终止开关，也不会在 VPN 停止后保护流量。请单独配置并验证客户端/操作系统保护。在 Android 上请检查目标设备的始终开启 VPN 和阻止未使用 VPN 的连接；FAV 未验证其可用性或行为。请使用专用服务器并保留控制台访问权限。二维码和 .conf 文件包含私钥，只应与目标设备共享。
