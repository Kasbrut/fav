# 你的第一台服务器

一步步的操作指南——无需任何先前经验。

## 1. 准备一台虚拟机

虚拟机（通常称为 VPS）是一台运行在数据中心、始终在线的小型计算机。你可以按月向云服务商租用，比如 Linode、DigitalOcean、Hetzner 或 Vultr。最便宜的套餐（通常是 1 个共享 CPU 核心和 1 GB 内存）就足够运行一个个人 [VPN](glossary://vpn) 了。

在下单服务器时，请选择最新的稳定版 Debian 或 Ubuntu 作为操作系统。在关闭服务商控制台之前，请记下三样东西：服务器的公网 IP 地址、登录用户名（通常是 `root`），以及服务商提供给你的密码。

## 2. 开放 WireGuard 端口

[防火墙](glossary://firewall) 是一个过滤器，决定哪些网络连接被允许进出你的服务器。大多数云服务商默认会启用防火墙，而它会阻止所有你没有明确开放的端口。WireGuard 通过 [UDP 端口](glossary://udp-port) 通信——默认是 51820——因此你需要添加一条入站规则，放行该端口上的 UDP 流量。

针对各大主要服务商的分步操作说明，请参阅本帮助部分中的 "防火墙与端口开放" 条目。每家服务商的控制面板看起来略有不同，但步骤都是一样的：找到防火墙规则，为端口 51820 添加一条入站 UDP 规则，然后保存。

## 3. 把服务器添加到本应用

打开「服务器」并选择添加服务器。填入公网 IP 地址、SSH 端口（默认 22）、用户名和第 1 步记录的密码。只有需要修改 WireGuard 端口、子网、DNS、加固、监控或备份时才检查高级选项，然后选择连接并安装。

应用会通过 [SSH](glossary://ssh)——一条加密通道——连接到你的服务器，并立即向你显示服务器的 [指纹](glossary://fingerprint)。指纹是一段唯一标识该服务器的短代码。请仔细核对，只有当它与你在服务商控制台或控制台输出中看到的内容相符时，才确认。一旦确认，应用就会记住它，并在它发生变化时向你发出警告——一次出乎意料的变化可能是安全问题的征兆。

## 4. 等待安装完成

确认指纹后，FAV 会检查服务器并开始安装。关闭应用后，安装仍会在服务器上继续。重新打开 FAV 可恢复进度；sudo 可能再次要求输入密码。

## 5. 添加你的第一个 peer

安装会创建第一个客户端配置。如需其他配置，请在服务器详情中添加对等端。在同一设备上保存或共享 .conf 文件，并用 WireGuard 打开。要导入到另一台设备，请在该设备上打开 WireGuard，选择通过二维码导入，然后扫描 FAV 显示的代码。

检查导入的隧道，保存并启用它。具体标签会因 WireGuard 平台和版本而异；对等端详情中提供了各平台的说明。

你的流量现在通过自己的服务器使用配置中的 IPv4 和 IPv6 默认路由。

## IPv6 与配置安全

FAV 会自动选择 IPv6。有服务商委派的 `/64` 和已验证的返回路径时，它使用路由 IPv6；否则使用持久 ULA：配置仍会捕获 IPv6，但服务器会拒绝它，而不是允许直接回退。没有 IPv6 绕过选项。

这验证的是服务器配置和 FAV 生成的配置文件，而不是导入它的设备。导出、声明已导入或握手都不能证明客户端路由、终止开关或 VPN 停止时的保护。在 Android 上，仅当可用时才启用 WireGuard 的始终开启 VPN 和阻止未使用 VPN 的连接，并在该设备上验证。其他平台请单独配置并测试客户端/操作系统保护。二维码和 .conf 文件包含私钥，只应与目标设备共享。
